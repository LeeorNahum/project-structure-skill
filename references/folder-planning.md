# Planning Folder

`Planning/` is an organizer folder for durable thinking, notes, constraints, and context that does not belong inside a separate repo for finalized deliverables. A planning repo lives at `Planning/Project-Plan/`, the canonical deliverable folder, with `Docs/` holding the active plan and `README.md` owning purpose and context.

## Initial Shape

```text
Planning/
└── Project-Plan/
    ├── AGENTS.md
    ├── README.md
    └── Docs/
```

This reference covers only creating the folder. For the full planning conventions, docs structure, Title Case naming, markdown frontmatter, one-topic-per-file discipline, and maintenance rules, install and follow the [`planning-repository-opinions`](https://github.com/LeeorNahum/planning-repository-opinions-skill) skill. Expansion beyond creating the folder is owned by that skill.
